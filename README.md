# 購入・返済プラン

外部ライブラリ・サーバー・データベース不要の静的Webアプリです。

## 起動

このフォルダーで以下を実行し、 http://localhost:8765 を開きます。

```sh
python3 -m http.server 8765
```

index.htmlを直接開くこともできますが、localStorageの扱いはブラウザによって異なるため、上記の方法を推奨します。

## ファイル構成

- index.html：日本語画面、入力表、スケジュール、通知・保存操作
- styles.css：表、固定列、横スクロール、スマートフォン向け表示
- calc.js：月・返済・端数・合計・終了年月の計算
- app.js：入力反映、localStorage、JSON入出力、ICS生成
- tests.cjs：計算テスト（`node tests.cjs`）

## 実装済み

- 初回はMac・カメラ・iPhoneのサンプルを表示
- 表で商品追加・編集・削除。価格の3桁区切り、数値の右揃え
- 購入年は現在年の前10年〜後30年（読み込み済み商品の年も保持）
- 月々の返済は価格÷回数の整数切り捨て、残額は最終回に支払い
- ローンと使用期間を独立管理。使用終了後の返済も合計に計上
- 青＝返済中、水色＝完済後使用中、グレー＝使用期間外
- 月ごとに同一幅の列、商品名固定、終了月のラベル、最下段に実際の月別合計
- 12か月・3年・5年・10年表示、前後の期間へ移動、任意の開始月
- 最後の商品の完済翌月に新商品を追加（既存の購入年月は変更しない）
- 使用終了翌月を買い替え予定月として計算
- 返済終了、買い替え6・3・1か月前、買い替え月の選択式ICS出力
- 各予定は月初1日の終日予定。VALARMは当日9時間後を指定（通知の扱いはカレンダーに依存）
- カレンダーには手動で読み込む。変更の自動同期なし
- 自動保存と復元（入力途中の空欄も復元）、JSON保存・読み込み、確認付き全データ初期化
- 不正値は計算から除外して注意を表示。インポートは形式・数値・ファイルサイズを検証
- JSON読み込みは現在の商品を置き換える前に確認
- 将来のcategory / salesUrlを商品データで保持可能。広告や外部送信は未実装

## データについて

保存は利用ブラウザとサイトのURLごとです。閲覧データの削除や別端末への変更ではデータが引き継がれないため、JSONでバックアップしてください。価格上限は1兆円、期間上限は1,200か月、JSON読み込みは200商品・2MB以内です。金利・手数料は含みません。

## 最新の表示変更

使用期間は年入力＋月数の自動換算に変更（6年＝72か月、1.5年＝18か月）。保存データは従来通り月単位で互換性を維持します。横スクロールを廃止し、狭い画面は入力を縦に配置します。チャートは画面幅に応じて3・6・12か月単位のブロックを縦に並べます。12か月・3年・5年・10年は引き続き選択可能です。淡いグレーの背景、白い面、丸い入力欄と青のアクセントに刷新しました。旧版の固定列・スワイプ案内は廃止しています。年/月換算と390px相当のチャート分割のDOM検証はPASS。実機での視覚確認は未実施です。

## 商品一覧の表表示

商品一覧は全画面幅で表を維持する3列構成（商品・価格／購入・期間／返済・予定）に変更。1商品1行で各列に項目をまとめ、iPhoneでも横スクロールなしで入力・削除できます。入力・削除・保存復元の既存DOMテストは再実行してPASS。実機での表示確認は未実施です。

## 独立列への変更

各情報を独立列に戻しました。使用年数と換算月数、通常返済額と最終回返済額、各終了年月も別々の列です。画面幅に収めるため「商品・購入・期間・返済・予定」の表示切り替えを設けています。商品名は全表示で共通です。

## 全列の常時表示

タブ切り替えを撤去し、全13列を常時表示します。横スクロールは使わず、見出し・表示値・商品名は折り返します。iPhoneの狭い幅では入力欄も細くなります。

## 入力・予定欄の更新

ローン月数はプルダウン、使用年数はプルダウンと手入力の切り替えに対応。最終回返済額・返済終了・使用終了・買い替え予定を1セルにまとめ、各行の削除ボタンを表の枠外に×で表示します。狭い画面では文字を縮小し、入力内容に合わせて入力欄の文字サイズも調整します。iPhone実機の視覚確認は未実施です。

## 文字・列幅の調整

使用（月）と月々の返済額を返済・使用予定セルへ集約し、商品一覧を7列に変更しました。

商品一覧は6列に変更。価格セルに月々の返済と最終回、ローンセルに返済終了、使用年セルに換算月数と使用終了を表示します。返済・使用予定列と買い替え情報を撤去しました。カレンダー出力は返済終了予定のみです。
